
# Jazz一次資料

ジャズ練習で信頼する一次資料の登録簿。AIメンター（jazz-mentor スキル）は、複数の流儀が
食い違ったとき、ここに挙がった資料を優先して準拠する。将来 `Knowledge/Zettel/` へ少しずつ蒸留する。

**運用**: この登録簿には資料へのリンクを載せる。出典の示し方は `AGENTS.md#常に守ること`、実体の保存先は `restructuring-vault` の「資料の保存」に従う。Web・動画・音源はURLを使い、書籍・論文は入手先と書誌情報からたどれるようにする。

追加時は「何に使う／なぜ信頼するか」を一言添えると、迷ったときの判断に効く。
