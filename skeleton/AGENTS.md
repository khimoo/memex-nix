# この Vault で働く AI へ

一人の利用者が、学んだことを自分の言葉で理解し、考えを育て、行動を続けるための Vault。AI はその作業を手伝い、判断と最終的な言い回しは利用者が持つ。

## 置き場

トップレベルは扱いで分ける。基準は `System/設計/2026-10-16-vault再設計.md#4. 置き場`。

- `Home.md` 今日の行動、期限、振り返り漏れ、未処理の入口。`Inbox/` 思いつきとWebクリップ。
- `Knowledge/` 知識と原稿。`Wiki/` 学問・技術・歴史などの体系の知識を抽象度の階層で置く。`Zettel/` 自分の経験と思考から生まれた知識（考察、手順、判断、出会った人物や作品）と構造ノート。`Reading/<資料が分かる名前>/` 資料ごとの章メモ、行間、演習、予想と計測。既存フォルダ名は保つ。`Writing/<原稿名>/` 原稿と材料。
- `LifeLogs/` 日々の記録。`Dailies/` 日次記録。`Reviews/` 週次・月次の振り返り。`Sessions/` AIセッションの記録。`Archive/` 今後の対応がなく、経緯や結果を参照するために残す取り組み。
- `LifeState/` 今の注意の向け方で分類する。`Action/` 今、能動的に注意を向けている対象。`Admin/` 今は忘れていたいが、忘れては困る対象（契約、住まい、学校の事務など）。`Someday/` 実施を約束していないが、選択肢として残したい取り組み。注意の向け方が変わったら移動する。
- `Assets/` 添付などの資料。資料の配置・Git管理・同期・表示は `.agents/skills/restructuring-vault/SKILL.md#資料の保存` に従う。
- `System/` 規則台帳、失敗記録、設計、計画、Bases、テンプレート、共有の参照資料。`.scratch/` AIの作業出力と変換の中間物（Git管理外。通常は消してよいが、移行の退避・評価記録は保存期限が決まるまで保持）。
- `README.md` 人間向けの案内。

## 常に守ること

- 精読、予想、演習の場面では、人間が考える部分を先回りしない。求められていない解答、ヒント、結果の見込みを出さない。学習が目的のため。
- 既存の文章の意味、語り口、構成を、依頼なしに変えない。人間の著作を守るため。
- 人間の知識・原稿・読書記録へのAIの追記は `> [!ai]` 区画で区別する。人間の文を守るため。あとで見返す印は利用者が選んだときだけ付け、解除の判断も利用者に残す。型と適用範囲は `System/参照/プロパティ.md#再検討` に従う。清書は本文で原本と頁を示す。
- 知識・原稿・読書の主張には、出典と頁・定理番号・計測ログなどの根拠の位置を直後に添え、確かめていない記述には `⚠️未検証:` を付ける。確認した事実、推測、まだ実行していないことを区別し、体験していないことを経験として書かない。読み手が確かさを判断できるように。実務の値には、確認した日と根拠を本文で結び付け、行動・運用・AI指示・設定はこの表示の対象外。
- 参照は読み手が一意にたどれる形で書く。見出しかブロック ID へのリンクを使い、見出しにない呼び名を作らない。出典はURL・ファイルリンク・タイトルなどと頁で示す。
- 数式は `$...$` の中に Typst 記法で書く。Typst Mate で描画するため。対応表は `System/参照/Typst記法.md`。
- 既存ノートに見える書き方、タグ、設定、一度の事例を、規則の根拠にしない。運用の意図が規約にないときは利用者に確かめる。
- 原本は置き場所にかかわらず読むだけとし、上書きせずコピーから加工する。原本を失わないため。
- Vault の外は読むだけにする。調査の依頼は書き込みの許可を含まない。書き込みの案は会話か `.scratch/` に出す。

## 確認の境界

- 次の操作は、実行の前に変更内容を示して承認を得る: 移動、改名、分割、統合、削除、6ファイル以上の一括変更、AI 指示と設定（`AGENTS.md`、`CLAUDE.md`、`.agents/`、`.claude/`、`.codex/`、`.obsidian/`）の変更、Vault 外への書き込み、生成物を Vault に採用すること。
- それ以外の依頼された編集は確認なしで行い、利用者が Git の差分で確かめる。コミットと push は利用者が行う。
- 承認は、示した対象と操作に限って有効。会話ですでに承認された範囲は再確認しない。何日もかかる作業は、`System/計画/` の計画書のうち `approved:` に日付があるものだけを実行する。

## 作業とスキル

- Wiki・Zettelを書く、編集する、リンクを足す、読書から転用する → `editing-knowledge`
- Zettel 候補を診断する → `lint-zettel`
- 数学書を精読する → `reading-math-closely`
- DB 実装の本を読み、予想と計測を検証する → `db-predict-measure`
- 手書きノートを清書する → `transcribe-handwritten-note`
- タスク、振り返り、長期ゴールを扱う → `reviewing-actions`
- AI セッションを要約する、セッションの目録を扱う → `summarizing-sessions`
- 実務資料を更新する → `updating-records`
- ジャズの練習を相談する → `jazz-mentor`
- 楽譜の画像を MusicXML にする → `score-image-to-musicxml`
- 練習フレーズを移調する → `transpose-12keys`
- ノートを移動、改名、分割、統合、削除する、一括で変える → `restructuring-vault`

スキルが一覧に出ないときも、`.agents/skills/<名前>/SKILL.md` を直接読んで従う。

## 指示の改訂

規則の追加と改訂は `revising-instructions` で行う。規則ごとの目的と正本の場所は `System/規則台帳.md` にある。
