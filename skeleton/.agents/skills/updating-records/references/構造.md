# Admin の構造の目安

`updating-records` が参照する。一つの対象に1ノートを置く。次のうち、その対象に必要な情報だけを本文に書く。

## 現在の事実

契約内容、金額、機器の型番などを、その値に対応する根拠・原本へのリンクと一緒に書く。確かめたときだけ確認日を添え、未確認なら未確認と書く。

## 次に注意すること

次に注意を向ける条件（`updating-records` の「規則」を参照）。

## 用事

進行中手続きのタスク（`updating-records` の「規則」を参照）。

## 原本・添付

原本は保存先へのリンクで開くか、必要なときに埋め込む。資料の実体の保存と Git 管理は `restructuring-vault` に従う。

## 履歴

変更日、旧値から新値、根拠を残す。
