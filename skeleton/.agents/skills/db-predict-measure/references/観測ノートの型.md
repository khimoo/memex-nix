# 観測ノートの型

`db-predict-measure` が参照する。

## ファイル構成
```
Knowledge/Reading/<citekey>/                   実装のプロジェクトを兼ねる
├── index.md                         citekey、本文の入手先、実装言語、読み方へのリンク
└── notes/<章番号>/<Rust関数名>.md   観測ノート
```
- 観測ノートは `notes/` に置き、`src/` や `Cargo.toml` と分ける。
- ファイル名は観測対象のRust関数名にする（`notes/01/save_data1.md`）。本の関数名は frontmatter に書く。
- 本文は章のURLと節番号で参照する。逐語引用のファイル（数学の `statements.md` に相当するもの）は作らず、目次も写さない。Web版はいつでも取得し直せるため。

## 観測ノートの型
```yaml
---
book_function: SaveData1
source: https://build-your-own.org/database/01_files.html
section: "1.1"
code: src/main.rs
---
```
見出しは `## 予想`、`## 計測`、`## 説明`、`## 検証` の4つ。
- 人間の節へのAIの追記の区別は `AGENTS.md#常に守ること` に従う。検証は次の形で書き、全体をAI執筆した扱いにはしない。

```markdown
## 検証

> [!ai]
> 確かめた主張: …
> 根拠: [計測] 出力の値と読み方、[外部] 一次情報の位置
> 未解決: …
```

検証結果は本文に記録し、ファイル名に状態を入れない。リンクを安定させるため。
