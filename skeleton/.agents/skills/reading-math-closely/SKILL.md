# 数学書の精読

始める前に `System/参照/学習支援.md` を全文読む。学習支援に共通の目的と態度は、そちらが正本。

## 目的

人間が教科書を理解し、定義・順序・道具立ての意図を汲めるようにする。

## 本文の所在

「教科書に書いてある」と言えるのは提示された本文だけ。本文がない箇所は「該当箇所の本文が必要」と返す。捏造を防ぐため。

## 外部情報の扱い

- 数学の中身は外から持ってこない。教科書の証明を、他書や Web の証明で置き換えたり補ったりしない。
- 書誌、正誤表、用語や記法の流儀、定義や命名の歴史は必要に応じて検索してよい。
- 人間が教科書の外を問えば検索し、`[外部]` と出典を添える。
- 内部知識だけの一般論はその旨を述べ、未確認として扱う。

## 出典ラベル

主張には次のどれかを付ける。

- `[本文]` 教科書に明記されている
- `[補完]` 本文にはないが、既出の定義や定理から機械的に埋まる
- `[外部]` 教科書の外の一般的な数学の知識
- `[推測]` 未検証（`⚠️未検証:` と同じ意味）

## 態度

- 先回りの境界は `AGENTS.md#常に守ること` に従う。著者の意図を理解するために求められた説明は、この境界の中で行う。
- 教科書の誤りや誤植が疑われるときは `[推測]` として指摘する。黙って正しいほうに読み替えない。

## 検証の判断

依頼範囲の各段階を定義・既出の定理・論理規則で正当化できるか確かめる。埋まらなければ「未完了」とし、箇所を特定する。「概ね正しい」で済ませない。判断の限界は `System/参照/学習支援.md#検証の意味` を参照する。

## 記法

- 数式は `AGENTS.md#常に守ること` と `System/参照/Typst記法.md` に従う。
- 記号と用語は教科書の表記に合わせる。教科書と違う記法を使うときは明示する。自分の記号の取り決めはWikiの該当領域の入口ページに登録された記号と用語で確かめる。
- 日本語で応答し、専門用語は初出のときに原語を添える。

## ワークフロー

1. 検証・説明・アウトライン・保存の依頼範囲を分けて受け取る。全文の検証は全文の依頼があるときだけ行う。
2. `Knowledge/Reading/<citekey>/statements.md` を起点に本文を読み、根拠に必要な既出の定義・定理や節の切れ目まで読み足してよい。所在表は索引であって本文の代わりでも読む上限でもない。検証・出力・保存の範囲は広げない。
3. 依頼箇所を検証し、チャットは「依頼範囲では穴が見つからなかった」か「未完了：（箇所）」、詳細は依頼された場所へ書く。人間が自分で考える箇所には着手しない。
4. アウトラインは依頼された範囲について出し、人間が展開を指定した項目だけをルートに子を1〜7個作る。定義の展開や単なる式変形にしかならなくなったら、これ以上分解する意味がないと述べて止める。
5. 保存を依頼された検証結果・アウトライン・説明だけを命題ファイルに記録する。保存の確認区分は `AGENTS.md#確認の境界` に従う。
6. 使用した既出結果の番号・頁・逐語の主張を `statements.md` に追記し、節の `index.md` の依存関係を更新する。未使用の定理や未依頼の検証は保存しない。

保存時は `references/ファイル構成.md` を読む。

## アウトライン

- 各項目の本文上の対応を確かめ、対応しない項目は外す。
- 対象と性質を名指しする。「〜性を示す」「〜の言葉へ翻訳する」のようなメタ語彙は本文との対応が曖昧になるため、対象が持つ性質を直接書く。
- 命題をルートとする木にする。親の項目に主張を書き、その主張が成り立つ根拠を子の項目に書く。
  - 最上位の項目は、すべて成り立てばルートの命題が従う主張にする。
  - 子の項目には、親の主張の根拠（定義、既出の定理、他の項目、計算）だけを書く。
  - 「AなのでB」はBを親、Aを子に分ける。
  - 各項目は真偽を判定できる文にし、「〜を繰り返す」などの考えの流れと区別する。
  - 原文が省いている主張は、独立した注記にせず、その主張の項目に `[補完]` を付けて示す。
  - 各項目の直下の子は1〜7個。
- 細部の計算は展開時に譲り、子の項目の余地を残す。

例は `references/アウトラインの例.md`。

## 段落の参照

- `## 検証` の段落には「検証1」「検証2」…の段落名とブロックID（`^step1` など）を付ける。
- 別の段落を参照するときは、番号や呼び名だけで書かず、ブロック ID へのリンクにする。同じファイルの中なら `[[#^step2|検証2]]`、別のファイルやチャットなら `[[Knowledge/Reading/<citekey>/<節番号>/<命題名>#^step2|<命題名> 検証2]]`。
- 表示名は段落名と一致させる。正本は `AGENTS.md#常に守ること`。
