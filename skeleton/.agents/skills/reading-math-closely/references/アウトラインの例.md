# アウトラインの悪い例と良い例

`reading-math-closely` の「アウトライン」の節の例。

## 対象と性質を名指しする

- 悪い例: 「分解不可能性の否定を、射影の像の言葉へ翻訳する」
- 良い例: 「$lim_(arrow.l) f = H union K$（$H, K$ は真部分連続体）という仮定を、$H$, $K$ の射影の像が $I$ に一致しない番号の存在に置き換える」

## 主張と根拠を分ける

- 悪い例: 「4と5を $H_(q-2),dots,H_(q-k+1)$ についても繰り返す。$r$ 番目で成り立った性質から、$r+1$ 番目でも同じことが成り立つ」
- 良い例: 親「$r=0,dots,k$ のすべてで (\*) が成り立つ」、その子「$r=0$ で成り立つ」「$r<k$ で成り立てば $r+1$ でも成り立つ」、さらにその子にそれぞれの根拠

## 定義と仮定を、使う項目より前に置く

- 悪い例: 項目 1.3 の主張「$J = psi^(-1) (R_c)$ は $[0, oo)$ に一致する」の中で $J$ を導入し、兄弟の項目 1.4 でも $J$ を使う。1.4 から見ると、$J$ が有効な範囲が分からない
- 良い例: 項目 1.3 を定義「$J = psi^(-1) (R_c)$ とおく」にし、主張「$J = [0, oo)$ である」を 1.4 に置く。$J$ を使う項目は、すべて 1.3 の後ろの兄弟かその子孫になる

## 仮定を、外す主張の中で閉じる

- 悪い例: 仮定「ある $T in (0, oo)$ で $J = [0, T)$ と仮定する」を最上位に置き、その後ろに主張「$K_(c') = emptyset$ である」と、結論「$J = [0, oo)$ である」を並べる。結論まで仮定の範囲に入ってしまう
- 良い例: 仮定を外した主張を親にし、仮定と矛盾をその子に置く。

  1. 主張「どの $T in (0, oo)$ でも $J != [0, T)$ である」
     1. 仮定「ある $T in (0, oo)$ で $J = [0, T)$ と仮定する」
     2. 主張「$K_(c') = emptyset$ である」（根拠は 1.1 と、$overline(R_c) = X$ であること）
     3. 主張「$K_(c') != emptyset$ である」（根拠は $f$ の不動点）
  2. 主張「$J = [0, oo)$ である」（根拠は 1 と、$J$ が $[0, T)$ か $[0, oo)$ の形であること）

  親の主張 1 は 1.2 と 1.3 の矛盾から従い、1.1 の仮定には依存しない。2 は 1.1 の仮定の範囲の外にある。
  仮定を置かずに、子に「$J = [0, T)$ ならば $K_(c') = emptyset$」と「$K_(c') != emptyset$」を並べてもよい。どちらの形でも、親に「ゆえに $J != [0, T)$」に当たる主張を置き、結論をつなぐ。
